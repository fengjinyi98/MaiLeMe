# 买了么（MaiLeMe）V1.0 PRD

最后更新：2026-02-28  
版本：V1.0（MVP）

## 1. 产品定位

“买了么”是一款带黑色幽默风格的反向消费与闲置管理工具。  
核心目标：通过冷静期机制、使用成本可视化和毒舌式反馈，帮助用户减少冲动消费、提升物品使用率。

## 2. 目标用户

- 深夜直播间/短视频平台高频冲动下单用户
- 经常“买前高频研究，买后长期闲置”的用户
- 有存钱、极简生活、FIRE 倾向的年轻用户

## 3. MVP 目标

- 完成“想买 -> 冷却 -> 决策 -> 已买管理 -> 使用追踪 -> 看板反馈”的单机闭环
- 1 周内可开发出可自用版本
- 不引入账号系统与中心化后端

## 4. 核心功能范围（V1.0）

### 4.1 模块 A：冲动小黑屋（冷却期管理）

功能点：
- 新增待购商品：名称、价格、图片（可选）、冷静期天数（3/7/15/自定义）
- 列表展示冷静期剩余天数
- 冷静期到期后可选择：
  - 忍住没买（计入“省下金额”）
  - 破戒购买（流转到“闲置榨干机”）

验收标准：
- 用户可在 30 秒内完成一条待购录入
- 到期商品可完成一次且仅一次结果决策
- “忍住没买”的金额会进入看板累计

### 4.2 模块 B：闲置榨干机（ROI 追踪）

功能点：
- 新增已购物品：名称、买入价、目标单次成本
- 每次使用支持一键打卡
- 实时计算当前单次使用成本 = 买入价 / 使用次数
- 展示“回本进度条”（当前成本接近目标成本的进度）

验收标准：
- 任意物品可连续打卡并实时更新成本
- 使用次数从 0 到 1 时计算正确，不出现除零异常
- 进度条与成本数值一致

### 4.3 模块 C：毒舌看板（统计与激励）

功能点：
- 展示“靠意念省下的总金额”
- 展示“吃灰最严重 Top 3”（按最近使用时间排序）
- 本地通知输出毒舌文案（如 N 天未使用提醒）

验收标准：
- 看板数据可从本地持久化数据实时聚合
- Top 3 排序规则稳定、可复现
- 本地通知可定时触发并支持关闭

## 5. 非目标（V1.0 不做）

- 社交排行榜
- 室友共享/多人协作
- 跨平台账号体系
- 中心化后端管理后台

## 6. 关键指标（MVP 观察）

- 冷静期完成后“忍住没买”比例
- 用户 7 日内打卡次数
- 吃灰物品数量变化
- 累计省下金额增长曲线

## 7. 版本演进

- V1.0：本地优先（SwiftData，单机闭环）
- V1.5：CloudKit 私有同步（换机不丢数据）
- V2.0：如需社交/商业化，再引入 Firebase 或自建 Go + PostgreSQL
