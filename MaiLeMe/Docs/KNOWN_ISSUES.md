# 买了么（MaiLeMe）已知问题清单

最后更新：2026-03-04

## KI-2026-03-04-001 通知中心未显示 App 图标

- 严重级别：中
- 状态：待排查（暂不阻塞当前功能迭代）
- 影响范围：真机本地通知在通知中心展示时，左侧未出现预期 App 图标

### 现象描述

- 预期：本地通知在锁屏/通知中心中展示 App 图标。
- 实际：当前测试机在通知中心看不到预期图标（或被系统样式弱化为无明显图标）。

### 已完成排查

- 已确认工程 `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`。
- 已补齐 `AppIcon` 多尺寸资源（包含 `20x20@2x/@3x` 等通知相关尺寸）。
- 已确认构建产物可编译通过（`BUILD SUCCEEDED`）。
- 已通过“后台延时通知”场景复测，问题仍存在。

### 初步判断

- 该问题可能与 iOS 通知样式策略、系统缓存或特定系统版本行为有关，非业务通知调度逻辑错误。

### 临时策略

- 该问题先记录为已知问题，不阻塞当前主功能与上线准备。
- 后续在真实发布链路（Release/TestFlight）和多机型上复测。

### 后续行动

- 在不同 iOS 版本与机型复测（含锁屏、通知中心、横幅三种场景）。
- 使用 Release 构建与 TestFlight 包分别验证显示差异。
- 若持续复现，收集系统日志并整理最小复现工程提交 Apple Developer Technical Support。
